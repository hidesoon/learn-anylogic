# Annotation Interface AnyLogicLegacyAPI

---

```
@Target({TYPE,METHOD,FIELD,CONSTRUCTOR})
@Retention(CLASS)
@AnyLogicLegacyAPI
@Documented
public @interface AnyLogicLegacyAPI
```

Classes, methods and fields marked with this annotation are from old versions of AnyLogic,
they are supported and may be called by user. The only difference is that they
aren't displayed in the code completion
