# Variables view

[Working with views](https://anylogic.help/anylogic/ui/working-with-views.html)[Debug view](debug-view.md)

The **Variables** view displays information about the variables associated with the stack frame selected in the [**Debug** view](debug-view.md). When debugging a model, variables can be selected to have more detailed information be displayed in the **Detail pane**. In addition, Java objects can be expanded to show the fields that variable contains.

![](https://anylogic.help/advanced/debug/images/variables_view.png)The Variables view. The detail pane is the area at the bottom of the view displaying text.

To show or hide the Variables view

1. Choose **View > ![](https://anylogic.help/anylogic/ui/images/views/Variables_view.gif)Variables** from the main menu.

The **Variables** view toolbar provides a set of toolbar buttons that allow to customize the view:

| Command | Action |
| --- | --- |
| **Show Type Names** | Defines whether variables' type names are shown in the view. |
| Show Logical Structures | Defines whether logical structures are shown in the view. |
