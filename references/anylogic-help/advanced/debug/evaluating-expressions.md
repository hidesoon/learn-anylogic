# Evaluating expressions

[Breakpoints](breakpoints.md)[Expressions view](expressions-view.md)[Stepping through the execution of a model](stepping-execution.md)

When the VM suspends a thread (due to hitting a [breakpoint](breakpoints.md) or stepping through code), you can evaluate expressions in the context of a stack frame.

Expressions can be entered and evaluated in the **Detail Pane** (in the [**Expressions** view](expressions-view.md) and [**Variables** view](variables-view.md)).

To add an expression

1. In the **Expressions** view, right-click (macOS: Ctrl + click) in the view area and select **Add Expression** from the popup menu.
2. The **New watch expression** dialog box will be displayed. Type the expression in the **Expression** field.

   ![](https://anylogic.help/advanced/debug/images/add_expression.png)
3. The checkbox **Enable** defines, whether this expression will be enabled. Deselect it if you want to disable the expression.
4. Click **OK** when finished.
