# Locating the error log file

The AnyLogic application runtime errors are printed into the AnyLogic log file. When contacting the [AnyLogic Support Team](https://anylogic.help/anylogic/ui/support-services.html), you can be asked to provide this log file.

The log file location depends on your operating system. Please follow the given instructions to locate the file.

* **Windows:**
  > "\Users\*<user name>*\.*<AnyLogic edition name>*\Workspace8\.metadata\.log

  where user name is the name of the user account and AnyLogic edition name can be AnyLogicPLE, AnyLogicProfessional, or AnyLogicUniversity depending on the edition used.
  **Example**:
  "C:\Users\forrest.gump\.AnyLogicProfessional\Workspace8\.metadata\.log"

  ![](https://anylogic.help/advanced/debug/images/log_file.png)

  The file may appear to have no name if you do not have file extension display enabled in your Windows Explorer.
* **macOS:**
  > "*Home folder*/.*<AnyLogic edition name>*/Workspace8/.metadata/.log"

  where Home folder is the name of the user’s home folder and AnyLogic edition name can be AnyLogicPLE, AnyLogicProfessional, or AnyLogicUniversity depending on the edition used.

  This folder is hidden. To make it visible, open Home folder and press Command + Shift + . on your keyboard.
* **Linux:**
  > "~/.*<AnyLogic edition name>*/Workspace8/.metadata/.log"

  where AnyLogic edition name can be AnyLogicPLE, AnyLogicProfessional, or AnyLogicUniversity depending on the edition used.
