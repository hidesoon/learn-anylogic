# SVN

Subversion (often abbreviated SVN, after the svn command) is a software versioning and revision control system distributed under an open source license. Developers use Subversion to maintain current and historical versions of files. It is intended to be a largely compatible successor to the widely used Concurrent Versions System (CVS).
