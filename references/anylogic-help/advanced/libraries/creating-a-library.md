# Creating a library

To create a library

1. In the **Projects** view, right-click (macOS: Ctrl + click) any item of the model you are currently working with, and choose **New > Library...** from the popup menu.
2. The **New AnyLogic Library** dialog box is displayed.

   ![](https://anylogic.help/advanced/libraries/images/create_lib.png)
3. Specify the name of the new library in the **Name** field and optionally type the library description in the **Description** edit box.
4. Click **Finish** to complete the process.

When created a library, you will see the [library editor](library-editor.md) opened. There you can modify the general information about the library and specify how the library will appear in the **Palette**.
