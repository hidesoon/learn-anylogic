# Constants for units

Time
:   | Constant | Time units |
    | --- | --- |
    | MILLISECOND | milliseconds |
    | SECOND | seconds |
    | MINUTE | minutes |
    | HOUR | hours |
    | DAY | days |
    | WEEK | weeks |
    | MONTH | months |
    | YEAR | years |

Length
:   | Constant | Length units |
    | --- | --- |
    | MILLIMETER | millimeters |
    | CENTIMETER | centimeters |
    | METER | meters |
    | KILOMETER | kilometers |
    | INCH | inches |
    | FOOT | feet |
    | YARD | yards |
    | MILE | miles |
    | NAUTICAL\_MILE | nautical miles |

Rate
:   | Constant | Rate units |
    | --- | --- |
    | PER\_MILLISECOND | per millisecond |
    | PER\_SECOND | per second |
    | PER\_MINUTE | per minute |
    | PER\_HOUR | per hour |
    | PER\_DAY | per day |
    | PER\_WEEK | per week |
    | PER\_MONTH | per month |
    | PER\_YEAR | per year |

Speed
:   | Constant | Speed units |
    | --- | --- |
    | MPS | meters per second |
    | KPH | kilometers per hour |
    | FPS | feet per second |
    | FPM | feet per minute |
    | MPH | miles per hour |
    | KN | knots |

Acceleration
:   | Constant | Acceleration units |
    | --- | --- |
    | MPS\_SQ | meters per second2 |
    | FPS\_SQ | feet per second2 |

Rotation speed
:   | Constant | Rotation speed units |
    | --- | --- |
    | RPM | revolutions per minute |
    | RAD\_PER\_SECOND | radians per second |
    | DEG\_PER\_SECOND | degrees per second |

Amount
:   | Constant | Amount units |
    | --- | --- |
    | LITER | liters |
    | OIL\_BARREL | oil barrels |
    | CUBIC\_METER | cubic meters |
    | KILOGRAM | kilograms |
    | TON | tons |

Flow rate
:   | Constant | Flow rate units |
    | --- | --- |
    | LITER\_PER\_SECOND | liters per second |
    | OIL\_BARREL\_PER\_SECOND | oil barrels per second |
    | CUBIC\_METER\_PER\_SECOND | cubic meters per second |
    | KILOGRAM\_PER\_SECOND | kilograms per second |
    | TON\_PER\_SECOND | tons per second |
